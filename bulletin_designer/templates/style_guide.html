Bulletin style guide

Logo

Use the full-color logo on white and the white logo on parish green. Keep clear space equal to the cross height; never stretch, recolor or crop it.

Typography

  • Minimum size anywhere: 12 pt. Body 12.5-13 pt, section headings 18 pt, titles 24-26 pt.
  • Headings: Helvetica/Arial bold. Body: Georgia (serif) for easy print reading.
  • Per-section text options (Sections overview, next to each section): Font style and Text size. Sizes below 12 pt are an exception the designer must choose deliberately, for example to fit a full week of Mass Intentions in a half-width column.

Layout

  • Letter size (8.5 x 11 in), 0.6 in margins. Page count is always a multiple of 4; leftover pages are notes pages.
  • Cover carries the table of contents. Every page has a running header and "Page N of M" footer.
  • Each section gets a set number of pages (Admin > Sections). Cut-off content is flagged in the preview.

Images

  • Never stretched or cropped: width and height scale together (object-fit: contain).
  • Alternative text is required unless the image is marked decorative.

Accessibility (Section 508 / WCAG 2.1 AA)

  • Semantic landmarks, skip link, visible focus, labelled fields, table headers with scope, no color-only meaning.
  • Publish the printed PDF as tagged PDF where possible, and link the web version.

Content and sources

Standing sections (staff, welcome, food pantry, ministries) carry forward each week. Weekly sections (calendar, Mass intentions and ministers, readings, pastor's message, prayer list) must be submitted each week. Material from usccb.org, miamiarch.org and stpeterbpk.org must be attributed in the Source field.
